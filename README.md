# Telco Customer Churn Prediction

Welcome to the official project repository and presentation website for the **Telco Customer Churn Prediction** project.

---

## 📌 Project Overview
Customer attrition (churn) is a critical challenge for telecommunication service providers. This project focuses on building a predictive analytics solution using machine learning and statistical modeling to identify customers at high risk of canceling their service. 

By analyzing user demographic traits, service sign-ups, and account characteristics from over 7,000 records, our predictive model enables stakeholders to execute targeted retention strategies, safeguard recurring revenue, and enhance customer lifetime value.

* **Course / Context:** IT4793 - Applied Data-Driven Solutions
* **Target Stakeholders:** Telecom Business Owners & Executive Leadership
* **Primary Evaluation Metrics:** $F_1$-score and PR-AUC (Precision-Recall Area Under Curve)
